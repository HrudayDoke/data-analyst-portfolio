# Hrudaynath Balasaheb Doke — Data Analyst Portfolio

An interactive, animated portfolio highlighting data analysis, business intelligence, reporting, and visualization work.

## Pages

- **Home:** portfolio overview, skills, internship impact, and visualization gallery
- **Projects:** selected analytics projects
- **Project details:** KPI reporting, retail MIS, and customer churn
- **Contact:** email, phone, LinkedIn, and GitHub

## Run locally

Open `index.html` in a browser. The site is built with HTML, CSS, and JavaScript and does not require a build step.

The visualization gallery currently contains illustrative examples; replace these with original dashboard screenshots or live dashboards when available.

## Pages deployment

This repository can be published as a static site with GitHub Pages by selecting the `main` branch and `/(root)` folder in the repository's Pages settings.
